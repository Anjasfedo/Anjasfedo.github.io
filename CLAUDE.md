# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Personal portfolio (anjasfedo.github.io): TanStack Start + React 19, Vite 8, Nitro v3 (beta), Tailwind v4, Biome. Single package, no tests.

## Commands (pnpm only)

- `pnpm dev` — dev server on `:3000` (falls back to `:3001` if busy; check output before opening a browser)
- `pnpm build` — static build; deployable site lands in `.output/public` (README's `dist/` path is stale)
- `pnpm check` — `biome check` (lint + format + import sorting); run before finishing. `pnpm lint` / `pnpm format` for the parts.
- `pnpm generate-routes` — regenerate `src/routeTree.gen.ts` (also regenerated by dev/build). Never hand-edit it.
- No test or typecheck script. `npx tsc --noEmit` works if a typecheck is needed; don't add a script for it.

`pnpm check` fails on HEAD (mixed tab/space indentation, CRLF endings, 7 a11y lint errors in the modals, 2 `organizeImports` assists) — treat that as baseline, don't mass-reformat. After `pnpm build`, Biome also lints the generated `.output/public/index.html`; run `pnpm check` before `pnpm build`. See `AGENTS.md` for the file-by-file breakdown.

## Architecture

- **Static site on GitHub Pages.** `vite.config.ts` uses `nitro({ preset: 'github-pages' })`; `.github/workflows/*` (manual `workflow_dispatch`) builds and uploads `.output/public`. No server runtime in production — don't add server functions/API routes expecting them to work live.
- **Routes** (`src/routes/`): `__root.tsx` is the HTML shell (`shellComponent`), all `<head>` SEO/OG/JSON-LD meta, and `notFoundComponent`; `index.tsx` is the whole portfolio page; `404[.]html.tsx` prerenders `/404.html` for Pages fallback. No `index.html` exists — don't create one.
- **Content is data, not JSX.** Portfolio entries live in `src/data/*.ts` (experiences, projects, certificates, education, socialLinks), typed by `src/types/portfolio.ts`. Adding/editing a project or job = edit the data file (+ drop images in `public/`), not components.
- **Tabs**: `TABS`/`TAB_IDS` in `types/portfolio.ts` drive the tab strip in `index.tsx`, which maps each tab to a panel in `src/components/panels/`. Active tab syncs with the URL hash (`#projects` etc.), read after hydration so the prerendered default (`Experiences`) matches SSR. Detail views are `components/modals/`.
- **Asset URLs**: reference `public/` files via `` `${import.meta.env.BASE_URL}file.webp` ``, matching existing data files. Images are `.webp`.
- Experience `start`/`end` are month indices (`year * 12 + (month - 1)`), `end: null` = present.

## Design system — tokens win

- `DESIGN.md` is the spec (Linear-daylight); `src/styles.css` `@theme` implements it. Read both before UI work.
- Use token utilities, never raw hex (e.g. `bg-void text-mist bg-carbon border-graphite text-ash text-fog bg-acid-lime text-pitch rounded-badge shadow-cta`). `styles.css` renames some spec tokens (`--radius-badge`, `--shadow-cta`, `--shadow-card`, `--breakpoint-page`) — use implemented names.
- Spec constraints: one acid-lime CTA per view, font weights ≤590 (`font-medium` = 510), radii only 2/4/badge/6/12/full, hairline borders over shadows.
- Global CSS is linked as `../styles.css?url` in `__root.tsx` head — keep that pattern.

## Conventions

- Path aliases `#/*` and `@/*` → `./src/*` (existing code mostly uses relative imports).
- Strict TS: `noUnusedLocals`, `noUnusedParameters`, `verbatimModuleSyntax` (use `import type`).
- Biome only covers `src/**`, `.vscode/**`, `vite.config.ts`; excludes `routeTree.gen.ts` and `styles.css`. Style: tabs, double quotes.
- Vite plugin order matters: `devtools()` → `nitro()` → `tailwindcss()` → `tanstackStart()` → `viteReact()`.
- `AGENTS.md` holds the same guidance for OpenCode (Playwright MCP, Impeccable skill under `.opencode/`, and the `pnpm check` baseline failures); keep the two in sync.
