## Overview

Pulih Apps was the capstone project for Bangkit Academy 2024, built by a cross-functional team of machine learning, mobile, and cloud computing cohorts.

## My Role

As the **Cloud Computing** member, I was responsible for designing and deploying the backend infrastructure. The backend was built with **Django** and **Django REST Framework**, deployed on **Google Cloud Platform (GCP)** using **Cloud Run** for serverless container execution and **Cloud SQL** for the PostgreSQL database.

I set up API endpoints, managed authentication and data flow, and configured cloud services to ensure the application was production-ready and scalable.

## Key Experience

This project gave me end-to-end experience in cloud-native backend development — from writing RESTful APIs to containerizing the application and deploying it on a serverless platform with proper IAM and security configurations.
