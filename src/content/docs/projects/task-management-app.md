**Status:** Production | **Tags:** Vue.js, Firebase, Tailwind, PWA, TypeScript

Full-stack task management application with real-time updates, perfect for teams of all sizes.

- [GitHub](https://github.com)
- [Demo](https://demo.com)

## Key Features

- Real-time sync across all devices
- Team collaboration with tasks, comments, and file sharing
- Progress tracking with visual Kanban boards
- Email and push notifications
- PWA support with offline capability

## Tech Stack

- **Frontend:** Vue 3, Composition API, TypeScript
- **Backend:** Firebase (Firestore, Auth, Storage)
- **Styling:** Tailwind CSS
- **PWA:** Service Worker with offline support
- **State Management:** Pinia
